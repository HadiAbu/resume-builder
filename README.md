# Resume Builder

> A living online CV and a reusable template other developers can deploy to
> organize and showcase their own GitHub projects. Plans are in
> `blueprint/project-plan.md` and `blueprint/build-plan.md`. See
> `blueprint/README.md` for how the Blueprint workflow works.

## Commands

- Dev server: `npm run dev` (http://localhost:3000)
- Build: `npm run build`
- Production server: `npm run start`
- Lint: `npm run lint`
